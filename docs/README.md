## 维护规则

- 设计决策写进对应设计文档或决策记录，不要散落在聊天或代码注释里。
- 每个任务结束时：更新 `02-项目计划/00-开发进度.md`；在 `06-开发记录/` 新增 `YYYYMMDD-T-XXX-<slug>.md`。
- 代码与文档冲突时以**代码**为准，并立刻回改文档；实现事实清单与代码冲突时，先判断是文档过期还是实现偏离。
- 接口、数据模型、事件类型、配置键或目录边界变更时，同步更新 `03-架构设计/03-实现事实清单.md`。
- 文档中 AI 产出、用户确认与验证证据必须区分标注；未实际验证的内容标为“待验证”。

# 安全与数据边界

> 本文描述已实现的安全措施、数据分类与已知限制。威胁建模与认证设计留待后续阶段。

## 1. 网络边界

- 服务仅绑定 `127.0.0.1`（`apps/server/src/index.ts`）。
- **Host 校验**：请求的 `Host` 必须精确等于 `127.0.0.1:<实际端口>`，否则返回 421。
- **Origin 校验**：非安全方法（POST 等）的 `Origin` 必须为 `http://127.0.0.1:<实际端口>`；非生产环境额外允许 `http://127.0.0.1:5173`（开发界面）。缺少 Origin 同样拒绝（403）。
- **响应头**：`X-Content-Type-Options: nosniff`、`X-Frame-Options: DENY`、`Referrer-Policy: no-referrer`，以及 CSP `default-src 'self'; base-uri 'none'; object-src 'none'; frame-ancestors 'none'; script-src 'self'; style-src 'self'; connect-src 'self'`。

**不提供**：用户认证；防御同机其它进程；防御全部 DNS rebinding 情形。Loopback 不构成身份验证。

## 2. 数据分类

| 类别 | 处理 |
|---|---|
| 任务目标、验收标准 | 入库（用户已确认） |
| 步骤输入摘要（分工摘录，≤ 800 字符） | 入库 |
| 参与者输出（含模型回答） | 入库，作为讨论室内容与步骤输出；可能包含敏感信息，由用户自行管理数据库文件 |
| 产物（最终结论） | 入库 |
| 事件（消息为中文说明，不含提示词正文） | 入库 |
| 完整交接简报 | 不入库；仅在调用过程中存在于内存 |
| 凭据（API Key、token、Cookie、`auth.json`） | 不入库，不入 Git，不写入日志与文档；本项目不读取上游凭据文件 |
| 完整上游会话或 transcript | 不入库 |
| 日志 | 仅记录事件名、错误名、计数与状态；不记录提示词、输出或凭据 |

## 3. 路径与授权

- **工作目录**：可选；必须是已存在的绝对路径；仅 Codex 参与者使用，且沙箱为 `read-only`。本项目不授予任何写入权限。
- **默认工作目录**：`<数据目录>/codex-scratch`，为空目录，不访问项目目录。
- **授权范围**：用户选择参与者与工作目录即视为本次任务的授权，且仅限只读。授权不扩展到其它目录或动作。
- **不推断权限**：界面可见或调用成功不等于获得额外的目录、系统或服务权限（见 `AGENT.md` §10.2）。

## 4. 子进程

- 不经 shell；参数以数组传递；`windowsHide: true`。
- 提示词经 stdin 传入，不出现在命令行中。
- 不使用 `--dangerously-bypass-approvals-and-sandbox` 或任何绕过审批、沙箱的开关。
- 中止时结束进程树（Windows：`taskkill /T /F`）。
- stderr 不对外展示；stdin 的写入错误被吞掉，结果由退出码判定。

## 5. 输入与错误

- 请求体在 `task-input.ts` 中校验；超长输入直接拒绝，不静默截断。
- 用户可见的错误消息为中文，不包含内部细节。
- 未知异常只返回通用的 500 响应；错误名可写入服务端日志，但不写消息。

## 6. 已知限制与待验证

- Loopback 无认证：同机其它进程可以访问 API（须由用户知晓）。
- Codex 只读沙箱的强度由上游实现决定；本机仅验证了写文件被拒绝这一项。
- `node:sqlite` 为实验性 API，升级 Node 时须复核。
- 模型输出已入库；若需删除，须人工删除数据库文件（不提供自动清理）。
- 服务绑定地址的任何改动（包括容器内绑定 `0.0.0.0`）都属于安全边界变更，须用户批准。
- agent 或插件可能以服务账号身份获得较高的宿主权限；“工具隐藏”或“插件接口”不是隔离机制。路径、命令与密钥的限制必须由服务端强制执行，并记录实际生效的配置。
- 工作目录现状为可选，缺省为专用空目录；未对敏感位置（盘符根、用户主目录、系统目录）做限制。目标为 codex 参与者必须由用户显式指定目录，敏感位置需二次确认，对话中调整需留痕（见 [`06-第5期目标设计.md`](06-第5期目标设计.md) §2.1、§14）。
- 子进程 stdout 目前无大小上限；目标增加上限，超出即中止调用（待第 5 期实施）。

# 分期路线图与审批门槛

> 本文件是阶段范围与验收口径的唯一事实源。各期的实际完成情况见 `00-开发进度.md`，细节证据见 `06-开发记录/`，获批范围见 `03-阶段基线/`。

## 推进规则

阶段按序推进。每期完成后汇报产物、验证结果、未决风险和建议，再停止等待用户明确批准。未获批准不得开始下一期或实施顺手功能。阶段批准只覆盖对应路线图范围与验收口径。

## 第 0 期：目录骨架与项目文档

**目标：**建立目录骨架、项目规则、项目说明、阶段路线、架构概述和决策记录。

**范围边界：**仅 Markdown 文档与目录；不添加应用代码、依赖或构建配置。

**状态：**已完成。

## 第 1 期：接入与风险验证（只读调查）

**范围：**只读调查 Codex、Hermes、DSH 的本机路径、协议、权限及消息/事件能力；核实 DSH `127.0.0.1:3080` 服务身份；审查 Paseo 架构与协作工作流。未启动模型任务、安装依赖或变更 agent/profile/服务/凭据配置。

**交付：**见 `03-架构设计/05-接入调查/`。

**状态：**已完成（只读调查）。

## 第 2 期：本机应用底座

**目标：**建立 React + Vite 前端、Fastify 本机服务、SQLite 元数据初始化与健康检查；提供基础状态页面，不建设任务或 agent 功能。

**安全与数据边界：**服务仅绑定 `127.0.0.1`；校验 Host 与写请求 Origin；生产默认仅允许本机页面来源；SQLite 默认置于当前用户本机应用数据目录。

**获批范围与验收基线：**见 `03-阶段基线/第2期-本机应用底座.md`。

**状态：**已完成（已提交 `be06b01`）。

## 第 3 期：协作调度

**目标：**建立 agent 选择、适配器契约，以及协调者分工和多轮讨论两种模式。

**验收标准：**先用模拟 adapter 验证两种模式；可见参与者及调用状态；支持暂停、取消、超时、失败反馈和调用预算；不默认传递完整历史。

**获批范围与实施决定：**见 `03-阶段基线/第3期-协作调度.md`。

**状态：**自动化验收完成，待用户验收。

## 第 4 期：任务工作台

**目标：**实现讨论室、动态步骤时间线及产物审阅。

**验收建议：**展示步骤、状态、负责人、输入输出及产物；阻塞、暂停、失败、完成清晰可辨；刷新可恢复已保存状态。

**获批范围与实施决定：**见 `03-阶段基线/第4期-任务工作台.md`。

**状态：**自动化验收完成，待用户浏览器验收。

## 第 5 期：提示词、上下文与记忆 — 待批准

**目标：**管理协作与角色提示词版本、任务上下文快照，按需检索证据并按 Flash Vault 规则协作记忆。

**验收建议：**任务可追溯启动时版本；变更不影响运行中任务；共享材料来源可审阅纠正；不复制整个 Vault。

## 第 6 期：受控任务执行 — 待批准

**目标：**按任务授权范围执行工作，呈现过程、产物与文件差异。

**验收建议：**默认只读；写入由服务端限制于授权路径/动作；变更可追溯；越界、删除、覆盖、不可逆及外部写入须人工确认。

## 第 7 期：工作台自我改进 — 待批准

**目标：**在隔离环境提出与验证工作台改进，由用户决定是否发布。

**验收建议：**结果和差异可审阅；未批准不发布；版本切换只作用于新任务。

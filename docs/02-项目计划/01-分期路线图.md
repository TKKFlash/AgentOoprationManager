# 分期路线图与审批门槛

> 本文件是阶段范围与验收口径的唯一事实源。各期的实际完成情况见 `00-开发进度.md`，细节证据见 `06-开发记录/`，获批范围见 `03-阶段基线/`。

## 推进规则

阶段按序推进。每期完成后汇报产物、验证结果、未决风险和建议，再停止等待用户明确批准。未获批准不得开始下一期或实施顺手功能。阶段批准只覆盖对应路线图范围与验收口径。

## 第 0 期：目录骨架与项目文档

**目标：**建立目录骨架、项目规则、项目说明、阶段路线、架构概述和决策记录。

**范围边界：**仅 Markdown 文档与目录；不添加应用代码、依赖或构建配置。

**状态：**已完成。

## 第 1 期：接入与风险验证（只读调查）

**范围：**只读调查 Codex、Hermes、DSH 的本机路径、协议、权限及消息/事件能力；核实 DSH `127.0.0.1:3080` 服务身份。未启动模型任务、安装依赖或变更 agent/profile/服务/凭据配置。

**交付：**调查记录已迁入知识库，不在本仓库。

**状态：**已完成（只读调查）。

## 第 2 期：本机应用底座

**目标：**建立 React + Vite 前端、Fastify 本机服务、SQLite 元数据初始化与健康检查；提供基础状态页面，不建设任务或 agent 功能。

**安全与数据边界：**服务仅绑定 `127.0.0.1`；校验 Host 与写请求 Origin；生产默认仅允许本机页面来源；SQLite 默认置于当前用户本机应用数据目录。

**获批范围与验收基线：**见 `03-阶段基线/第2期-本机应用底座.md`。

**状态：**已完成（已提交 `be06b01`）。

## 第 3 期：协作调度

**目标：**建立 agent 选择、适配器契约，以及协调者分工和多轮讨论两种模式。

**验收标准：**先用模拟 adapter 验证两种模式；可见参与者及调用状态；支持暂停、取消、超时、失败反馈和调用预算；不默认传递完整历史。

**获批范围与实施决定：**见 `03-阶段基线/第3期-协作调度.md`。

**状态：**自动化验收完成，待用户验收。

## 第 4 期：任务工作台

**目标：**实现讨论室、动态步骤时间线及产物审阅。

**验收建议：**展示步骤、状态、负责人、输入输出及产物；阻塞、暂停、失败、完成清晰可辨；刷新可恢复已保存状态。

**获批范围与实施决定：**见 `03-阶段基线/第4期-任务工作台.md`。

**状态：**自动化验收完成，待用户浏览器验收。

## 第 5 期：对话式工作台与检查点续跑 — 待批准（提案，2026-10-12）

**编号说明：** 本提案插入第 5 期，原第 5–7 期顺延为第 6–8 期。历史记录（T-004、T-005、第 3/4 期基线）保留原编号。是否接受重排由用户决定（见 `03-架构设计/06-第5期目标设计.md` §17）。

**目标：**

1. 创建任务时由用户指定工作目录：含 Codex 等需要工作目录的参与者时必填；敏感位置需显式确认；对话中可调整并留痕。
2. 讨论室改为对话框：用户可随时插话（广播或定向）、调整设置、结束讨论。
3. 参与者输出按字段标签保存；下游按策略选择性注入，超出预算时记录裁剪。
4. 检查点续跑与分叉；服务重启后的任务标记为“已中断”，由用户选择续跑、分叉或结束，不自动续跑。
5. 不同适配器并行、同一适配器串行；超时由引擎强制执行；取消增加中间态。
6. 同一适配器的多个参与者须有不同角色定位。

**设计依据：** `03-架构设计/06-第5期目标设计.md`。

**验收建议：** 见该文档 §16 的 10 项。

**多智能体接入（可拆分批准，2026-10-12 提案）：** Claude CLI、DSH headless、Hermes（受限）的规划见 `03-架构设计/07-智能体接入规划.md`。本期只做能力契约与替身测试，不做真实接入；真实只读验证逐个适配器单独批准。是否将接入并入第 5 期由用户决定。2026-10-13 拆出 **ACP 基座** 作为独立子交付：先完成基座与假 ACP 替身测试，再分别批准 Claude（ACP）与 DSH（ACP）的真实只读验证。

**前置与边界：** 数据库迁移至 v4（只追加）；`prompts/` 版本化提示词与记忆不在本期（第 6 期）；真实模型调用仍须用户另行批准。

**状态：** 待批准。未获批准不得开始。

## 第 9 期：仪表盘与差异化界面 — 待批准（提案，2026-10-13）

**目标：** 在第 5–8 期完成后，提供仪表盘与差异化工作台能力。

1. 仪表盘：运行中、已完成、结论不完整的任务数；调用已用与上限；最近事件流；参与者表现（平均耗时、失败率、沉默率、被跳过次数）。
2. 差异化：检查点时间线（可从此处分叉）、预算与成本视图、标签化结论分栏、只读边界可视化、降级结论解释。

**依据：** `01-前端设计.md` §8、`03-架构设计/06-第5期目标设计.md` §13。

**验收建议：** 汇总数据由服务端接口计算，前端不做聚合；进行中的任务可读，且不影响运行中的任务；每个数字可追溯到事件或步骤；视觉风格以本项目设计为准；动效遵守 `prefers-reduced-motion`。

**状态：** 提案，待批准；编号与范围待用户确认。

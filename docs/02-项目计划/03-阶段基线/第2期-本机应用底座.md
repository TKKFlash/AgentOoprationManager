# 第 2 期实施基线

日期：2026-10-10  
状态：用户于 2026-10-10 确认，可用于本期实现；不授权第 3 期。

## 已确认范围

- 目标为个人 Windows 本机单用户应用；Web 与 API 均只绑定 `127.0.0.1`，不提供 LAN/公网访问。
- Host 仅接受对应服务的 loopback 主机名；写请求需有严格匹配的 Origin。开发期仅增加 Vite 的 `http://127.0.0.1:5173`。
- SQLite 默认放入 Windows `%LOCALAPPDATA%\AgentOperationsManager`；可用 `AOM_DATA_DIR` 或 `AOM_DATABASE_PATH` 明确覆盖。
- 本期只初始化元数据 schema，并验证 SQLite 读写；不保存任务正文、agent 对话、提示词、密钥或调用记录。
- 实现服务启动、SIGINT/SIGTERM 关闭、启动失败清理、通用错误响应及不含敏感内容的日志策略。
- 第 2 期验收：类型检查、生产构建、自动测试、本机 loopback 健康检查、SQLite 读写检查，并说明启动和停止方式。自动化检查不代表用户本人验证。
- 暂使用 Node.js 24 的 `node:sqlite`，避免原生依赖构建脚本；该内置 API 当前仍标记为实验性，后续升级/迁移应重新评估。

## 当前阶段边界

- 允许完成 React/Vite + Fastify + SQLite 的运行底座、基础状态界面、健康端点和必要验证。
- 不实施 agent 连接器、任务创建/调度、对话、完整任务存储、提示词/记忆工作流或受控文件写入；这些属于后续阶段。
- 任何超出以上基线的持久化字段、外部服务集成或破坏性行为，先询问用户。

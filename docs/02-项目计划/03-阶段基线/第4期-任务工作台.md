## 1. 目标与验收建议

**目标：**实现讨论室、动态步骤时间线及产物审阅。

**验收建议（来自路线图）：**展示步骤、状态、负责人、输入输出及产物；阻塞、暂停、失败、完成清晰可辨；刷新可恢复已保存状态。

## 2. 范围

- 任务空间列表（轮询刷新）。
- 新建任务表单：目标、验收标准、协作方式、参与者（按选择顺序）、预算、只读工作目录（仅 Codex 参与者）。
- 讨论室：头部信息、暂停/继续/取消、参与者状态条、讨论内容、动态步骤、产物、事件日志。
- 刷新恢复：以 `seq` 游标从 0 读取完整快照，之后增量同步；终态后停止轮询。

**不在范围内：**推送式实时同步、产物的非文本格式、差异审阅（第 6 期）、界面的完整无障碍审查。

## 3. 实施决定

以下决定由实施过程作出，待用户确认，同时记录在 `02-决策记录.md`。

1. **同步方式：**轮询 + `seq` 增量（任务列表 3 秒，讨论室约 1.2 秒）。
2. **状态展示：**状态使用统一的颜色语义（运行中为蓝色，已暂停为琥珀色，完成为绿色，失败与超时为红色，取消与跳过为灰色）。
3. **产物定义：**产物仅为最终结论；讨论发言作为步骤输出显示在讨论室。
4. **控制范围：**暂停、继续、取消；取消后任务状态在运行循环结束时才写入终态，界面通过轮询获知。
5. **输入校验：**超长文本直接拒绝，不静默截断，避免用户误以为内容已完整保存。

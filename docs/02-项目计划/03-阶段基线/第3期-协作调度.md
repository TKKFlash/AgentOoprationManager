## 1. 目标与验收标准

**目标：**建立 agent 选择、适配器契约，以及协调者分工和多轮讨论两种模式。

**验收标准（来自路线图）：**先用模拟 adapter 验证两种模式；可见参与者及调用状态；支持暂停、取消、超时、失败反馈和调用预算；不默认传递完整历史。

## 2. 用户确认的范围决策

1. **持久化：**服务端 SQLite 完整持久化任务简报、步骤状态、参与者输出与产物。凭据、完整上游对话与密钥仍不入库。
2. **适配器验证：**以模拟 adapter 作为两种协作模式的自动化验收；另批准一次真实只读验证。实际执行超出该次数，已在 T-004 记录中说明。

## 3. 范围

- 适配器契约与能力声明（`packages/shared`、`packages/agent-adapters`）。
- 适配器：`mock`（默认，不调用模型）；`codex-cli`（固定只读沙箱，须显式选择）。
- 两种协作模式：协调者分工、多轮讨论。
- 可见参与者与调用状态；暂停、继续、取消、单次超时、失败反馈；调用预算。
- 最小简报与裁剪摘录；不向工作参与者广播其他参与者的发言。
- 任务、步骤、产物、事件的持久化（SQLite schema v2）。

**不在范围内：**提示词版本管理（第 5 期）、证据与已确认事实的输入入口（字段保留为空）、受控写入（第 6 期）、Hermes 与 DSH 接入。

## 4. 实施决定

以下决定由实施过程作出，待用户确认。

1. **协调者：**第一位参与者担任协调者，先输出分工，格式为 `- 参与者名：分工内容`。
2. **分工回退：**无法解析时使用默认分工，并记录 `plan.adjusted` 事件。
3. **互不可见：**工作参与者之间不共享发言；综合阶段只接收各自的摘录。
4. **讨论模式：**按轮次依次发言；每位只看到其他参与者的最新摘录；轮数或预算用尽后由第一位参与者收敛。
5. **摘录上限：**800 字符，超出截断并加省略号；完整输出保存在步骤中。
6. **预算：**调用开始即计数，失败与超时同样占用；非最终步骤为综合或收敛保留 1 次；预算不足则跳过该步骤并记录 `budget.exhausted`。
7. **终态：**`completed`（结论完整）、`completed` 且 `degraded`（结论不完整）、`failed`（未产生结论）、`cancelled`（用户取消）。
8. **暂停：**只在步骤边界生效，不打断进行中的调用。
9. **取消与超时：**引擎统一计时，并通过同一 `AbortSignal` 中止调用；适配器只需遵守信号。
10. **服务重启：**未结束的任务标记为“未完成”，不续跑。
11. **同步：**前端以 `seq` 游标轮询，不做推送。

## 主要结论（摘要）

- DSH `127.0.0.1:3080` 的监听进程为 `pnpm dsh web`，属于浏览器 UI，不是已确认的 Agent API。

- Hermes `-z` one-shot 自动绕过交互审批；`acp --check` 因缺少依赖失败；API Server 是否启用未核实。
- DSH ACP 的 `authenticate` 不做认证，只能作为本机受信子进程，不能暴露为网络服务。

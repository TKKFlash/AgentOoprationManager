## 背景

第 2 期目标：建立前端、本机服务与 SQLite 元数据初始化，提供基础状态页面；不建设任务或 agent 功能。安全与数据边界见基线文档。

## 实现内容

- pnpm workspace 配置与共享的 TypeScript 基线（`tsconfig.base.json`）。
- `apps/server/`：Fastify 服务；Host 与 Origin 校验；安全响应头；健康检查 `/api/health`；生产环境提供前端静态文件；启动与关闭处理。
- `apps/server/src/database.ts`：SQLite 元数据初始化（schema v1，仅 `app_meta`）与读写自检。
- `apps/web/`：基础状态页面（总览）。
- `Dockerfile`、`.dockerignore`：已添加，未验证。
- 文档：`README.md` 运行说明、`PHASE-2-DECISIONS.md` 基线（迁移至阶段基线目录）。

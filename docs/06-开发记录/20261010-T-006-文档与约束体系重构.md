## 背景

用户要求参照 `erp-agent-sys` 的文档结构与约束，拆分重写本项目文档，并建立便于后续 agent 参考的进度记录。

参照项目的结构要点：

1. **约束单一事实源**：`AGENT.md` 是唯一约束来源；`AGENTS.md`、`CLAUDE.md` 只作为入口指针，列出必读顺序。
2. **文档按编号分层**：`00` 总览、`01` 前端、`02-项目计划`（进度、路线图、决策、Git 规范）、`03-架构设计`（含实现事实清单）、`04-开发运维`、`06-开发记录`。
3. **进度文件只记当前状态与任务看板**，阶段内容指向路线图，不复制。
4. **每个任务一份开发记录**，文件名为 `日期-任务号-标题.md`，包含基本信息、背景、实现内容、数据与接口变更、测试与证据、有意排除项、遗留问题与下一步。
5. **维护规则**：代码与文档冲突以代码为准；接口或模型变更须同步事实清单。

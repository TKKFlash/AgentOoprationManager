# 分期路线图与审批门槛

## 推进规则

阶段按序推进。每期完成后汇报产物、验证结果、未决风险和建议，再停止等待用户明确批准。未获批准不得开始下一期或实施顺手功能。阶段批准只覆盖对应路线图范围与验收口径。

## 第 0 期：目录骨架与项目文档 — 已完成

**目标：**建立目录骨架、项目规则、项目说明、阶段路线、架构概述和决策记录。

**验收结果：**目录与文档已建立；未添加应用代码、依赖/构建配置。自动结构检查通过；用户本人验证未进行。

## 第 1 期：接入与风险验证 — 已完成（只读调查）

**范围：**只读调查 Codex、Hermes、DSH 的本机路径、协议、权限及消息/事件能力；核实 DSH `127.0.0.1:3080` 服务身份；审查 Paseo 架构与协作工作流。未启动模型任务、安装依赖或变更 agent/profile/服务/凭据配置。

**交付：**[`INTEGRATION-RESEARCH.md`](INTEGRATION-RESEARCH.md)、[`PASEO-COMPARISON.md`](PASEO-COMPARISON.md)。

**验收结果：**报告区分本机检查、来源结论及待验证项；链接检查通过；未实施 adapter。用户本人验证未进行。Codex CLI、DSH Headless 仅为候选；真实事件、取消与 sandbox 未端到端验证。Hermes one-shot 会绕过交互审批；DSH ACP 不含协议认证，只可研究受控 stdio 边界。

## 第 2 期：本机应用底座 — 已完成（2026-10-10）

**范围与验收基线：**见 [`PHASE-2-DECISIONS.md`](PHASE-2-DECISIONS.md)。

**目标：**建立 React + Vite 前端、Fastify 本机服务、SQLite 元数据初始化与健康检查；提供基础状态页面，不建设任务/agent 功能。

**安全与数据边界：**服务仅绑定 `127.0.0.1`；校验 Host 与写请求 Origin；生产默认仅允许本机页面来源；SQLite 默认置于当前用户本机应用数据目录；本期不落任务、对话、提示词、密钥或调用记录。

**验收结果：**`pnpm typecheck`、`pnpm build`、`pnpm test` 均通过；自动测试 7 项通过，覆盖 loopback 绑定、健康与 SQLite 状态、Host/Origin 拒绝策略、生产页面、路径配置及进程启动。开发环境 Web 页面、API 与 Vite 代理均返回 HTTP 200。实际数据库在 `%LOCALAPPDATA%\AgentOperationsManager\agent-operations-manager.sqlite` 创建，已只读核验仅含 schema 版本和启动时间元数据。用户本人尚未在浏览器验收。

**交付：**workspace 配置、基础状态 UI、Fastify health endpoint、安全默认项、本机 SQLite 元数据初始化、运行说明及本期边界文档。未建 agent adapter、任务/对话存储或文件执行能力。

**限制/风险：**`node:sqlite` 为 Node 24 实验性 API，升级 Node 时应复核。Host/Origin 校验不提供用户身份认证，亦未证明能抵御所有 DNS rebinding 或恶意本机进程。Windows Ctrl+C 可停止开发服务；SIGTERM graceful shutdown 未实现，当前进程结束由终端管理。Docker 文件已添加但未经验证，且不属于本期验收。

## 第 3 期：协作调度 — 待批准

**目标：**建立 agent 选择、适配器契约，以及协调者分工和多轮讨论模式。

**验收标准：**先用模拟 adapter 验证两种模式；可见参与者及调用状态；支持暂停/取消/超时/失败反馈和调用预算；不默认传递完整历史。开始前另行确认协议及验收。

## 第 4 期：任务工作台 — 待批准

**目标：**实现讨论室、动态步骤时间线及产物审阅。

**验收建议：**展示步骤、状态、负责人、输入输出及产物；阻塞/暂停/失败/完成清晰可辨；刷新可恢复已保存状态。

## 第 5 期：提示词、上下文与记忆 — 待批准

**目标：**管理协作与角色提示词版本、任务上下文快照，按需检索证据并按 Flash Vault 规则协作记忆。

**验收建议：**任务可追溯启动时版本；变更不影响运行中任务；共享材料来源可审阅纠正；不复制整个 Vault。

## 第 6 期：受控任务执行 — 待批准

**目标：**按任务授权范围执行工作，呈现过程、产物与文件差异。

**验收建议：**默认只读；写入由服务端限制于授权路径/动作；变更可追溯；越界、删除、覆盖、不可逆及外部写入须人工确认。

## 第 7 期：工作台自我改进 — 待批准

**目标：**在隔离环境提出与验证工作台改进，由用户决定是否发布。

**验收建议：**结果和差异可审阅；未批准不发布；版本切换只作用于新任务。
